# Foundry VTT Setup

## 🎯 Objective
Successfully install, configure, and prepare Foundry VTT for running online TTRPG campaigns, including integration with existing campaigns and content.

## 💰 Investment
- **License**: $50 USD (purchased 2025-08-15)
- **Type**: One-time purchase, perpetual license
- **Account**: Need to create/access Foundry account for license key

## 🔧 Implementation Steps

### Phase 1: Installation & Basic Setup
- [x] Purchase Foundry VTT license
- [ ] Create/access Foundry VTT account
- [ ] Retrieve license key from user profile
- [ ] Download Foundry VTT software
- [ ] Install on primary machine
- [ ] Run initial setup wizard
- [ ] Configure basic settings

### Phase 2: Hosting Decision
- [ ] Evaluate hosting options:
  - [ ] Self-host (port forwarding required)
  - [ ] The Forge hosting service
  - [ ] Other cloud hosting options
- [ ] Set up chosen hosting method
- [ ] Test connection with another device

### Phase 3: Game System Setup
- [ ] Install game systems needed:
  - [ ] D&D 5e (if running D&D campaigns)
  - [ ] Daggerheart (when available)
  - [ ] Other systems as needed
- [ ] Configure system settings
- [ ] Import/create character sheets

### Phase 4: Content & Modules
- [ ] Browse and install essential modules:
  - [ ] Dice So Nice (3D dice)
  - [ ] Token Variants
  - [ ] Combat enhancements
- [ ] Import maps and assets
- [ ] Set up audio/music
- [ ] Configure scenes and lighting

### Phase 5: Campaign Migration
- [ ] Create first campaign world
- [ ] Import existing campaign notes/maps
- [ ] Set up player accounts
- [ ] Test run with players
